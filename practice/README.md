# Practice Material

This directory contains additional exercises created while preparing for the workshops.

- `llm/notes/` — study notes on LLMs, prompting, embeddings, RAG and agents.
- `llm/local-rag/` — local PDF retrieval and agent experiments using FAISS, Sentence Transformers and Ollama. The same original six-snippet FAISS retrieval can now be evaluated via OpenRAG Bench; see [the reproducible first-party evaluation guide](../docs/OPENRAG_BENCH_INTEGRATION.md).
- `yolo/` — compact detection and tracking practice scripts.
